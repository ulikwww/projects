# Академия умножения

Офлайн-игра для детей 8–12 лет на Python 3.12+ и Pygame 2.6.1. Интернет нужен только для первоначальной установки зависимости. Во время игры сервер, аккаунт и сеть не используются.

## Запуск в Windows

Откройте терминал в папке проекта:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

После установки можно запускать `run_windows.bat` двойным щелчком. Если установлен более новый Python, используйте его вместо `py -3.12` при создании среды.

В Linux:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python main.py
```

## Как играть

Создайте профиль ребёнка (до 24 символов), выберите таблицу ×2…×9. Второй множитель — от 1 до 10. Ответьте мышью или клавишами 1–4. После ответа нажмите «Дальше», Enter или пробел. Раунд содержит 10 вопросов; потеря трёх жизней завершает его раньше. Правильный ответ даёт 100 очков плюс бонус серии (до 100). Неправильный ответ показывает верное решение без ограничения времени на чтение.

На экране результата: верные ответы, ошибки, очки, лучшая серия и процент верных среди отвеченных вопросов. В «Мой прогресс»: освоение каждой таблицы, общий процент и до четырёх трудных примеров. Профили имеют независимые сохранения. Escape возвращает из меню прогресса/результатов; активный раунд покидается закрытием окна.

## Адаптивное повторение

Новые примеры имеют вес 4, освоенные — 0.35, остальные — `1.5 + 5 × ошибки / показы`. Выбор случайный с этими весами, одинаковые примеры подряд исключены, в том числе на границе раундов. После ошибки пример исключается из случайного выбора и назначается повтор после 3–5 других вопросов. Повтор переносится в следующий раунд. При выборе другой таблицы повтор ждёт возвращения к исходной таблице; несколько одновременно просроченных повторов выполняются по очереди, поэтому интервал может увеличиться.

Освоение: минимум 5 показов, минимум 80% верных от всех показов и текущая серия минимум 3. Закрытие окна до ответа оставляет показ в статистике без правильного ответа/ошибки — это консервативно влияет на освоение. Повтор после показа считается выполненным; новая ошибка назначает новый повтор.

## Сохранения

Папка и `progress.json` создаются автоматически. Windows: `%LOCALAPPDATA%\MultiplicationAcademy\progress.json`. На других системах: `~/MultiplicationAcademy/progress.json`. Для отдельной папки задайте переменную `ACADEMY_DATA_DIR`. Запись атомарная, после показа и ответа. Повреждённый JSON или неверная структура переименовываются в `progress-damaged-<id>.json`, создаётся чистое сохранение и показывается сообщение. Резервная копия сохраняется для восстановления. Запускайте одну копию игры одновременно: совместная запись нескольких процессов не поддерживается.

## Структура

```text
main.py                         точка входа
multiplication_academy/
  app.py                        события Pygame и переходы экранов
  config.py                     параметры окна и путь сохранений
  core/
    questions.py                примеры и варианты ответов
    adaptive.py                 веса и отложенное повторение
    progress.py                 модели, проверка и JSON-запись
    scoring.py                  очки, жизни и серии
    round.py                    состояние раунда
  screens/views.py              профили, меню, игра, результат, прогресс
  utils/ui.py                   кнопки, панели и системные шрифты
  data/                         место для будущих статических данных
  assets/                       место для будущих ресурсов
 tests/test_core.py              тесты алгоритма и сохранений
```

Изображения и внешние шрифты не нужны: интерфейс рисуется Pygame, используется доступный системный шрифт с кириллицей (Segoe UI, DejaVu Sans или Arial).

## Проверки

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe main.py --smoke
```

`--smoke` запускает настоящий игровой цикл Pygame с виртуальным экраном и временными сохранениями: создание профиля через события, меню, 10 ответов через клавиатуру, обратная связь, результат, прогресс, потеря трёх жизней и загрузка JSON. В Linux используйте `.venv/bin/python`.

Следующие этапы: звук с отключением, смешанные таблицы, повторение по дням, настройки доступности и сборка Windows `.exe` через PyInstaller. Сейчас это исходный Python-проект, не готовый установщик Windows.
